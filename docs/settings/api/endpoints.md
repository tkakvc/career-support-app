# エンドポイント一覧・詳細（設定）

認証（サインアップ・ログイン・ログアウト）のエンドポイントは [../../auth/api/endpoints.md](../../auth/api/endpoints.md) を参照。

| メソッド | パス | 概要 | 認証 |
|---|---|---|---|
| GET | /api/users/me | 自分のプロフィール取得 | 必須 |
| PATCH | /api/users/me | 表示名の変更 | 必須 |
| PUT | /api/users/me/password | パスワード変更 | 必須 |

## パスに `{id}` を持たない理由

- 操作対象は常にトークンのユーザー自身。`GET /api/users/{id}` の形にすると「他人のIDを指定する」経路が生まれてしまうため、`me` に固定する
- サーバー側は `@AuthenticationPrincipal UUID userId` で対象ユーザーを特定する

## メソッドの使い分け

| メソッド | 意味 | ここでの用途 |
|---|---|---|
| PATCH | リソースの一部フィールドだけ更新 | プロフィールの部分更新。現状の対象は表示名のみだが、項目が増えても「送ったフィールドだけ更新」を保てるよう PATCH にする |
| PUT | リソース（またはサブリソース）を丸ごと置き換え | パスワードは「新しい値で置き換える」1操作なので `me/password` に対して PUT |
