# エラー設計（設定）

認証系のエラーは [../../auth/api/error.md](../../auth/api/error.md) を参照。

## エラーコード一覧

| HTTPステータス | 内容 | 発生ケース |
|---|---|---|
| 400 | バリデーションエラー | 必須項目の欠落、文字数違反、newPassword が currentPassword と同一 |
| 401 | 認証エラー | JWT トークンが不正・期限切れ・未送信 |
| 403 | 現在パスワード不一致 | パスワード変更時、`currentPassword` が保存済みハッシュと一致しない |
| 500 | サーバーエラー | 予期しないサーバー内部エラー |

- 404 は発生しない：対象は常にトークンのユーザー自身であり、そのユーザーは認証を通った時点で必ず存在する

## エラーレスポンス形式

他APIと共通。

```json
{
  "error": "エラーメッセージ",
  "status": 400
}
```

## エンドポイント別エラーケース

### GET /api/users/me
| 条件 | ステータス |
|---|---|
| JWT 不正・未送信 | 401 |

### PATCH /api/users/me
| 条件 | ステータス |
|---|---|
| `displayName` が未送信・空文字 | 400 |
| `displayName` が100文字超 | 400 |
| JWT 不正 | 401 |

### PUT /api/users/me/password
| 条件 | ステータス |
|---|---|
| `currentPassword` が未送信・空 | 400 |
| `newPassword` が8文字未満 or 72文字超 | 400 |
| `newPassword` が `currentPassword` と同一 | 400 |
| `currentPassword` が現在のパスワードと一致しない | 403 |
| JWT 不正 | 401 |

---

## currentPassword 不一致を 403 にする理由

- 401 は「あなたが誰か分からない（認証できない）」を表す。パスワード変更の場面ではトークンで本人確認は済んでいるので 401 ではない
- 403 は「あなたが誰かは分かるが、この操作は許可できない」を表す。現在パスワードを言えない相手にパスワード変更をさせない、という意味で 403 が適切
- レスポンスメッセージは「現在のパスワードが正しくありません」に留め、アカウントの存在有無などの追加情報は出さない
