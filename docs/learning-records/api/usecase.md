# ユースケース・業務フロー（学習記録）

タグのユースケース（UC-06〜09）は [../../tags/api/usecase.md](../../tags/api/usecase.md) を参照。

## UC-01　学習記録を作成する

**アクター:** ログイン済みユーザー  
**目的:** 当日または過去の学習内容を記録する  
**事前条件:** JWT 認証済み

**正常フロー:**
1. 学習日・学習内容・学習時間・タグ（任意）を入力して送信する
2. 学習記録が保存され、作成したレコードが返る

**例外フロー:**
- `content` が空または2000文字超 → 400
- `duration` が 0 以下または 1440 超 → 400
- `date` が未来日 → 400
- 存在しない `tagId` を指定 → 404
- 認証トークン不正 → 401

## UC-02　学習記録一覧を取得する

**アクター:** ログイン済みユーザー  
**目的:** 過去の学習記録を一覧で確認する  
**事前条件:** JWT 認証済み

**正常フロー:**
1. 一覧を取得する（絞り込み条件は任意）
2. ログインユーザー自身の学習記録のみ返る

**絞り込みの組み合わせ:**
- タグ名のみ指定 → そのタグが付いた全期間の記録を返す
- `from` / `to` のみ指定 → 期間内の全記録を返す
- タグ＋期間を組み合わせて指定可

**例外フロー:**
- 認証トークン不正 → 401

---

## UC-03　学習記録を詳細取得する

**アクター:** ログイン済みユーザー  
**目的:** 特定の学習記録の詳細を確認する  
**事前条件:** JWT 認証済み

**正常フロー:**
1. 対象の学習記録IDを指定して取得する
2. 該当レコードの詳細が返る

**例外フロー:**
- 他ユーザーのレコードIDを指定 → 403
- 存在しないIDを指定 → 404
- 認証トークン不正 → 401

---

## UC-04　学習記録を更新する

**アクター:** ログイン済みユーザー  
**目的:** 誤った記録内容や学習時間を修正する  
**事前条件:** JWT 認証済み、対象レコードが存在する

**正常フロー:**
1. 対象の学習記録IDと更新内容を送信する
2. 更新後のレコードが返る

**備考:**
- PUT なので送られた `tagIds` でタグ紐付けを全置き換えする
- `tagIds` を省略・null・空配列のいずれの場合も「タグなし」として扱い、既存の紐付けを全解除する（フロントは毎回、変更後の最終状態を送る前提）

**例外フロー:**
- 他ユーザーのレコードIDを指定 → 403
- 存在しないIDを指定 → 404
- バリデーションエラー → 400
- 認証トークン不正 → 401

---

## UC-05　学習記録を削除する

**アクター:** ログイン済みユーザー  
**目的:** 不要な学習記録を削除する  
**事前条件:** JWT 認証済み、対象レコードが存在する

**正常フロー:**
1. 対象の学習記録IDを指定して削除する
2. 削除完了レスポンスが返る

**例外フロー:**
- 他ユーザーのレコードIDを指定 → 403
- 存在しないIDを指定 → 404
- 認証トークン不正 → 401
