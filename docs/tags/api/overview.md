# タグAPI 概要

このAPIは、学習記録に付与するタグの一覧取得・作成・編集・削除を行うためのものです。

## 主な機能
- タグ一覧取得（デフォルトタグ＋ユーザー作成タグ）
- タグの新規作成（ユーザー作成タグ）
- タグの編集（ユーザー作成タグのみ）
- タグの削除（ユーザー作成タグのみ）

## 想定ユースケース
- 学習内容をタグで分類し、検索や集計を容易にする
- ユーザーごとに独自タグを作成し、柔軟な管理を実現する

## 想定利用者
- Webエンジニア、ITエンジニア、転職活動中エンジニア

## タグ設計方針

学習記録には「デフォルトタグ（例：API, Linux, Javaなど）」と「ユーザーが自由に作成できるタグ」の両方を付与できるハイブリッド方式を採用する。

- デフォルトタグはシステム側で用意し、全ユーザーが利用可能
- ユーザーは独自のタグを新規作成・編集・削除できる
- 学習記録には複数のタグを付与可能
- タグは検索や集計にも利用する

## 共通仕様

| 項目 | 内容 |
|---|---|
| ベース URL | `/api` |
| 認証 | `Authorization: Bearer {JWT}` ヘッダー必須（認証不要のエンドポイントはない） |
| Content-Type | `application/json` |
| レスポンス形式 | JSON |
| 文字コード | UTF-8 |
