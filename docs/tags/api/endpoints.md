# エンドポイント一覧・詳細（タグ）

学習記録のエンドポイントは [../../learning-records/api/endpoints.md](../../learning-records/api/endpoints.md) を参照。

| メソッド | パス | 概要 |
|---|---|---|
| GET | /api/tags | タグ一覧取得（デフォルト＋ユーザー作成）|
| POST | /api/tags | タグ新規作成（ユーザー作成）|
| PUT | /api/tags/{id} | タグ名編集（ユーザー作成タグのみ）|
| DELETE | /api/tags/{id} | タグ削除（ユーザー作成タグのみ）|

## 詳細は request-response.md を参照
