# エラー設計（タグ）

学習記録のエラーケースは [../../learning-records/api/error.md](../../learning-records/api/error.md) を参照。

## エラーコード一覧

| HTTPステータス | 内容 | 発生ケース |
|---|---|---|
| 400 | バリデーションエラー | 必須項目の欠落、文字数超過 |
| 401 | 認証エラー | JWT トークンが不正・期限切れ・未送信 |
| 403 | 権限エラー | default タグの編集・削除、他ユーザーが作成したタグへのアクセス |
| 404 | リソース未発見 | 存在しない ID の指定 |
| 409 | 重複エラー | 同ユーザーで同名タグをすでに保有している |
| 500 | サーバーエラー | 予期しないサーバー内部エラー |

## エラーレスポンス形式

```json
{
  "error": "エラーメッセージ",
  "status": 400
}
```

## エンドポイント別エラーケース

### POST /api/tags
| 条件 | ステータス |
|---|---|
| `name` が空 | 400 |
| `name` が50文字超 | 400 |
| 同ユーザーで同名タグが存在する | 409 |
| JWT 不正 | 401 |

### PUT /api/tags/{id}
| 条件 | ステータス |
|---|---|
| 存在しないIDを指定 | 404 |
| default タグを指定 | 403 |
| 他ユーザーが作成したタグを指定 | 403 |
| 同ユーザーで同名タグが存在する | 409 |
| JWT 不正 | 401 |

### DELETE /api/tags/{id}
| 条件 | ステータス |
|---|---|
| 存在しないIDを指定 | 404 |
| default タグを指定 | 403 |
| 他ユーザーが作成したタグを指定 | 403 |
| JWT 不正 | 401 |

---

## 備考

- タグを削除しても、紐づく学習記録は削除されない。タグとの紐付けのみ解除される。
