# ユースケース・業務フロー（タグ）

学習記録のユースケース（UC-01〜05）は [../../learning-records/api/usecase.md](../../learning-records/api/usecase.md) を参照。

---

## UC-06　タグ一覧を取得する

**アクター:** ログイン済みユーザー  
**目的:** 学習記録に付与できるタグの一覧を確認する  
**事前条件:** JWT 認証済み

**正常フロー:**
1. タグ一覧を取得する
2. システム提供の default タグ全件 + ログインユーザーが作成した user タグが返る

**例外フロー:**
- 認証トークン不正 → 401

---

## UC-07　タグを作成する

**アクター:** ログイン済みユーザー  
**目的:** 既存タグにない分類で学習内容を整理するため、独自タグを作成する  
**事前条件:** JWT 認証済み

**正常フロー:**
1. タグ名を入力して作成する
2. type: "user"、createdBy: ログインユーザーIDのタグが作成され返る

**例外フロー:**
- 同じユーザーが同名タグをすでに持っている → 409
- `name` が空または50文字超 → 400
- 認証トークン不正 → 401

---

## UC-08　タグを編集する

**アクター:** ログイン済みユーザー  
**目的:** 作成済みの独自タグの名前を変更する  
**事前条件:** JWT 認証済み、対象タグが自分の作成した user タグである

**正常フロー:**
1. 対象タグIDと新しいタグ名を送信する
2. 更新後のタグが返る

**例外フロー:**
- default タグを指定 → 403
- 他ユーザーが作成したタグを指定 → 403
- 存在しないIDを指定 → 404
- 同名タグがすでに存在する → 409
- 認証トークン不正 → 401

---

## UC-09　タグを削除する

**アクター:** ログイン済みユーザー  
**目的:** 不要になった独自タグを削除する  
**事前条件:** JWT 認証済み、対象タグが自分の作成した user タグである

**正常フロー:**
1. 対象タグIDを指定して削除する
2. 削除完了レスポンスが返る
3. そのタグが紐づいていた学習記録のタグ紐付けは解除される（学習記録自体は削除されない）

**例外フロー:**
- default タグを指定 → 403
- 他ユーザーが作成したタグを指定 → 403
- 存在しないIDを指定 → 404
- 認証トークン不正 → 401
